# Security Gates

For security-relevant changes, evaluate:

- Authentication
- Authorization / RBAC
- Input validation
- Injection risks
- XSS / CSRF where applicable
- Secrets and configuration handling
- Session and token handling
- Rate limiting and abuse resistance
- File upload handling
- Data exposure and least privilege
- Auditability where required

Do not claim a security review was completed unless the relevant surfaces were actually inspected.
