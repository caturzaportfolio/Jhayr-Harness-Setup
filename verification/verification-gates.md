# Verification Gates

## Completion gate

- [ ] Acceptance criteria are satisfied.
- [ ] Relevant automated checks pass.
- [ ] Build/type checks pass where applicable.
- [ ] Runtime behavior is verified where applicable.
- [ ] No known critical regression exists.
- [ ] Final diff is in scope.
- [ ] Uncertainty is explicitly reported.

## Evidence rule

Never infer a successful check from code inspection alone when execution is available. Record the exact check and its result.
