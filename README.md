# Jhayr Harness Setup

A reusable, agent-neutral engineering harness derived from the **Agentic Engineering OS — ChatGPT Harness** and designed to operate inside real software repositories.

## Purpose

This repository turns engineering cognition into executable guidance for AI coding agents and human engineers. It is the operational harness layer; the broader Engineering OS remains the governance and lifecycle layer.

## Core principle

> Don't code first. Understand → Specify → Investigate → Plan → Execute → Verify → Review → Deliver → Learn.

## Operating lifecycle

`DISCOVER → DEFINE → SPECIFY → MODEL → ARCHITECT → PLAN → CONTEXTUALIZE → IMPLEMENT → VERIFY → REVIEW → SECURE → DELIVER → DEPLOY → OBSERVE → LEARN → ITERATE`

## Authority

The human owns product intent, scope, business rules, architecture decisions, constraints, and approval. Agents accelerate investigation, implementation, verification, and documentation. Git and observed runtime are executable truth.

## Repository status

This is the initial harness foundation. It is intentionally small, explicit, and agent-neutral. Future changes must preserve scope control and be verified against the harness itself.
