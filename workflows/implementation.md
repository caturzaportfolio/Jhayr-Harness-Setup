# Implementation Workflow

1. Re-read the objective, scope, constraints, and acceptance criteria.
2. Inspect the exact files before modifying them.
3. Follow existing repository patterns.
4. Make the smallest coherent change that satisfies the requirement.
5. Preserve unrelated behavior, UI, architecture, and files.
6. Add or update tests when needed to establish the new behavior.
7. Do not silently broaden the task.

After implementation, inspect the working diff before declaring success.
