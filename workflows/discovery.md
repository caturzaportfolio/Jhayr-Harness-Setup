# Discovery Workflow

**Goal:** understand the problem and current system before changing code.

1. Capture the requested outcome.
2. Identify product/domain context and acceptance criteria.
3. Inspect repository structure and relevant files.
4. Inspect dependencies, configuration, schema, APIs, tests, and existing patterns as applicable.
5. Establish current behavior from executable evidence where possible.
6. Record unknowns and risks.
7. Decide whether the task is sufficiently understood to proceed.

**Output:** bounded understanding, evidence, constraints, unknowns, and acceptance boundary.
