# Verification Workflow

A change is complete only when the strongest appropriate evidence supports it.

Check, as applicable:

- Acceptance criteria
- Type checks
- Lint
- Unit tests
- Integration tests
- E2E tests
- Build
- Runtime behavior
- Relevant database/schema behavior
- API contracts
- Final diff and repository scope

Do not report a check as passed unless it was actually run or directly observed. Report skipped checks and remaining uncertainty.
