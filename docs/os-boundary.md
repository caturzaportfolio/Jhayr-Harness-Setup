# OS Boundary

The **FULL Engineering OS for large scale systems** is the broader governance, lifecycle, architecture, and organizational operating system.

This repository is the **Agentic Engineering Harness**: the fast operational protocol used by an individual AI agent or engineer during a task.

The harness consumes context from the broader OS and returns implementation, verification, review, delivery, and learning evidence back to it.

## Relationship

`FULL Engineering OS → Agentic Engineering Harness → Coding Agent → Target Repository → Runtime`

Notion can remain the semantic/control plane. Git, tests, and observed runtime remain executable evidence.
