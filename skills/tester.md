# Tester Skill

**Role:** establish that the implementation satisfies requirements and does not introduce known regressions.

Responsibilities:
- Map acceptance criteria to verification cases.
- Test happy paths, edge cases, failure paths, and compatibility where relevant.
- Run the strongest practical automated checks.
- Verify runtime behavior when the task requires it.
- Report exact commands/checks and outcomes.
- Distinguish verified facts from unverified assumptions.
